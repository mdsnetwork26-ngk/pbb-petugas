Buat billing otomatis

eSPPT tidak menyediakan API publik, jadi “resep” request diambil dari browser Anda sekali saja: buka eSPPT > F12 > tab Network > klik tombol buat billing untuk 1 NOP > klik kanan request tersebut > Copy > Copy as cURL > tempel di bawah. Ganti nilai NOP/Tahun dengan placeholder. Uji dulu dengan dry-run.

Placeholder yang tersedia: {nop} {nop_no_dot} {tahun} {denda} {user}. Regex wajib punya grup penangkap atau mencocokkan angkanya.
Batasan yang jujur: membuat billing = menulis data ke sistem kabupaten. Saya tidak bisa login ke eSPPT dari sini, jadi templat di atas belum teruji terhadap form asli. Kalau regex/field-nya meleset, fitur ini hanya gagal (tidak merusak data Anda), dan Anda tetap bisa menempel kode billing manual di menu Antrean Billing.
